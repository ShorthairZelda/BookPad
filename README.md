# BookPad 1.1 · 手柄阅读控制

原生 Swift / AppKit / Apple GameController 应用，无第三方依赖。此构建适用于 Apple 芯片 Mac，macOS 13 或更高版本。

在 [Releases](https://github.com/ShorthairZelda/BookPad/releases) 下载应用压缩包，解压后运行 `BookPad.app`。源码仓库不包含构建后的应用，使用 `./build.command` 可自行生成。

## 使用

1. 双击 BookPad.app。
2. 通过蓝牙或 USB 数据线连接 PS4 手柄。蓝牙配对时，关机状态下按住 PS + SHARE，直到灯条闪烁，在 Mac 蓝牙设置中连接。
3. 点击应用里的“授权辅助功能…”，在系统设置中启用 BookPad。如果列表中没有它，点击“+”并选中此文件夹内的 BookPad.app。
4. 打开 Apple Books，打开一本书并点击正文。
5. 点击“按键说明…”或菜单栏中的同名菜单，查看完整映射。

## 按键安排

| 操作 | 功能 |
| --- | --- |
| L1 / R1 | 上一页 / 下一页，轻按即可 |
| L2 / R2 深按 | 上一章 / 下一章，需超过 65% 行程 |
| 两个摇杆左 / 右 | 上一页 / 下一页 |
| 左摇杆上 / 下 | 本章开头 / 本章结尾 |
| 右摇杆上 / 下 | 放大 / 缩小字号 |
| 方向键 | 标准四向导航；正文中左右、上下均可翻页 |
| × | Return：确认选择或执行搜索 |
| ○ | Esc：取消、关闭弹出层，视图书当前界面而定 |
| □ | 添加当前页书签 |
| △ | 显示目录 |
| SHARE | 书内搜索，搜索文字仍需键盘输入 |
| OPTIONS | 切换全屏 |
| 触摸板按下 | 显示书签列表 |
| L3（左摇杆按下） | 显示笔记与高亮 |
| R3（右摇杆按下） | 恢复默认字号 |
| PS | 暂停 / 恢复映射，只在图书前台生效；系统可能拦截此键 |

高频翻页放在食指自然停靠的肩键上；章节操作需要深按扳机。× / ○ 遵循确认和取消的常见习惯。摇杆点击安排为低频功能，按下时忽略对应摇杆的偏移。触摸板目前使用按下操作。

快捷键依据：[Apple Books 官方快捷键说明](https://support.apple.com/en-mt/guide/books/ibk0a716cf4-9a70-485b-9835-72e3c7ed6c29/mac)。字号、章节、目录、书签等功能取决于书籍格式、键盘布局及当前界面；应用显示“已发送”只表示已提交操作，并非图书确认执行。

## 防误触与范围

按键按下单次触发，松开后才能再触发。摇杆需回到中心再推，中心死区 25%，触发阈值 60%，模糊的对角方向不触发。扳机须释放到 25% 以下才能再次触发。切换应用或恢复控制后，已经按住的按钮不会立即触发。

只在 Apple Books 位于前台且已授权时，直接向图书进程发送按键。PS 暂停 / 恢复仅操作本工具，因此在图书前台即使未授权也可使用（前提是系统转发了此按键）。同时出现不同操作时忽略，PS 暂停优先；同一时刻相同动作只发送一次。

反转方向交换摇杆、肩键的翻页方向及扳机章节方向，方向键保留标准导航，字号上下方向保持原样。

可在窗口中暂停控制。关闭窗口后继续运行，从菜单栏手柄图标重新打开或退出；不会自行设置开机启动。

## 权限和排查

辅助功能权限必须在系统设置中手动开启。更新使用本机临时签名的应用后，系统可能要求重新授权：退出 BookPad，在辅助功能列表中移除旧条目，再添加实际运行的 BookPad.app，然后重新启动。

如没有效果，先用键盘快捷键检查这本书是否支持该操作、正文是否获得焦点。搜索框获得焦点时，方向键会移动光标，× 执行搜索，○ 尝试退出。

## 源码与测试

安装 Xcode 或 Apple Command Line Tools 后，运行 `./build.command`。运行 `./test.command` 可执行输入状态与动作映射的 32 项检查。使用本机临时签名，不包含 Apple 公证。

- `StickGate.swift`：摇杆方向识别及回中逻辑。
- `ReadingAction.swift`：动作、快捷键、按钮与扳机防重复逻辑。
- `main.swift`：界面、手柄轮询、前台检查及图书按键发送。
- `Tests/main.swift`：输入与映射测试。

已通过本机编译、签名验证、32 项测试和界面检查。新版全部手柄按键在图书中的实际效果尚需重新授权并连接手柄后逐项验证。
